# 🍔 OrderIt - AI Powered Food Ordering App

## Features

- Restaurant Listing
- Restaurant Menus
- Search Restaurants
- AI Review Analysis
- Admin Dashboard
- Create/Delete Restaurants
- Stripe Payment
- Cloudinary Images
- MongoDB Atlas

## Tech Stack

- React
- Redux Toolkit
- Node.js
- Express.js
- MongoDB Atlas
- Cloudinary
- Stripe

## Installation

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
